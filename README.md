# Hoja de vida - Sebastián Felipe Vidal Enciso

Sitio web estático de hoja de vida preparado para publicarse con GitHub Pages.

## Archivos

- `index.html` — estructura y contenido.
- `style.css` — diseño responsive.
- `cv-sebastian-vidal.pdf` — hoja de vida original.

## Publicar con GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube estos archivos a la rama `main`.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` y la carpeta `/ (root)`.
6. Guarda los cambios y espera a que GitHub publique el sitio.

Si quieres un sitio personal, GitHub permite usar un repositorio llamado `TU_USUARIO.github.io`.
